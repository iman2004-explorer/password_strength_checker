Password Strength Checker
A lightweight desktop application built with Python and Tkinter that evaluates the security of a password based on industry-standard complexity requirements.

✨ Features
Real-time Analysis: Evaluates password strength based on five key criteria:

Length: Minimum of 8 characters.

Uppercase: Inclusion of at least one capital letter.

Lowercase: Inclusion of at least one lowercase letter.

Numbers: Inclusion of at least one digit (0-9).

Special Characters: Inclusion of symbols (e.g., @, #, $, %).

Visual Feedback: Displays strength levels (Strong, Medium, or Weak) using color-coded labels.

Detailed Requirements: Provides a pop-up alert listing exactly which security features are missing from the current password.

Secure Entry: Uses a masked input field (*) to keep passwords hidden from onlookers.

🚀 How to Run
Prerequisites
Python 3.x installed on your system.

The tkinter library (usually included with standard Python installations).
